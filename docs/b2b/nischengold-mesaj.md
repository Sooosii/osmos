## Gönderim günü — üç ölçüm, mesajdan ÖNCE

Üçü de 2026-08-18'de koşuldu ve geçti; gönderim günü **yeniden** koşulacak.

```bash
# 1. Demo ayakta mı
curl -s -o /dev/null -w "%{http_code}\n" -L https://nischengold.osmos.me/

# 2. 13 ürün adresi hâlâ duruyor mu (dükkân ürün kaldırmış olabilir)
grep -o "https://nischengold.com/products/[a-z0-9-]*" \
  src/data/tenants/nischengold/catalog.ts |
  while read u; do printf "%-72s " "$u"; curl -s -o /dev/null -w "%{http_code}\n" -L "$u"; done

# 3. Metne sayı EKLENDIYSE katalogu yeniden say (bugün 256)
curl -s "https://nischengold.com/products.json?limit=250&page=1" -o s1.json
curl -s "https://nischengold.com/products.json?limit=250&page=2" -o s2.json
node -e "let t=0;for(const p of ['s1','s2'])t+=JSON.parse(require('fs').readFileSync(p+'.json','utf8')).products.length;console.log(t)"
```

⚠️ **2. ölçüm atlanamaz.** Demo'nun bütün değeri "her yol sizin ürün
sayfanızda bitiyor" cümlesinde; kırık bir bağlantı o cümleyi ilk tıkta
yalanlar. Kırık bağlantı, bağlantısızlıktan kötüdür.

⚠️ Gönderdikten sonra deftere yaz, yoksa aynı mesaj ikinci kez gider:

```bash
cd leadgen && node src/cli.ts temas nischengold.com gonderildi
```
